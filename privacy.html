개인정보처리방침

최종 수정일: 2026년 8월 21일

요약 — 이 앱은 계정을 만들지 않고, 회원가입도 없으며, 사용자를 식별하는 정보를 수집하거나 서버에 저장하지 않습니다. 저장한 단어는 전부 사용자 기기 안에만 있습니다.

1. 수집하는 개인정보

없습니다. 이 앱은 이름, 이메일, 전화번호, 위치, 연락처, 기기 식별자 등 개인을 식별할 수 있는 정보를 일절 수집하지 않습니다. 로그인 기능이 없으며 광고 및 분석 도구(SDK)도 사용하지 않습니다.

2. 기기에 저장되는 정보

사용자가 만든 아래 데이터는 브라우저의 로컬 저장소(localStorage)에 사용자 기기 안에만 저장됩니다. 개발자를 포함한 외부에서 열람할 수 없습니다.

  • 추가한 단어와 단어장(뜻·발음·예문·학습 상태)
  • 화면 설정(언어, 밝은/어두운 테마)
  • 튜토리얼 표시 여부

이 데이터는 앱을 삭제하거나 브라우저의 사이트 데이터를 지우면 함께 삭제되며, 별도의 백업 서버가 없으므로 복구할 수 없습니다.

3. 외부로 전송되는 정보

사전 검색 기능을 쓸 때에 한해 입력한 검색어가 사전 조회를 위해 서버로 전달됩니다. 검색어는 조회 목적으로만 쓰이며 사용자 계정이나 신원과 연결되지 않고, 별도로 저장하지 않습니다.

이용하는 외부 서비스

  • 국립국어원 한국어기초사전 오픈 API — 단어의 뜻·발음·예문 조회. 검색어가 전달됩니다.
  • Vercel — 앱 호스팅 및 사전 API 중계. 일반적인 웹 서버 운영 과정에서 접속 기록(IP 주소 등)이 일정 기간 남을 수 있습니다.
  • Google Fonts · jsDelivr — 글꼴 파일 제공. 글꼴을 내려받는 과정에서 해당 서비스에 접속 정보가 전달될 수 있습니다.

발음 듣기는 기기에 내장된 음성 기능 또는 사전에서 제공하는 녹음 파일을 재생하며, 이 과정에서 사용자의 음성을 녹음하거나 마이크에 접근하지 않습니다.

4. 앱이 요구하는 권한

이 앱은 카메라, 마이크, 위치, 연락처, 저장소 등 어떠한 기기 권한도 요구하지 않습니다. 사전 검색과 발음 재생을 위해 인터넷 연결만 사용합니다.

5. 아동의 개인정보

이 앱은 개인정보를 수집하지 않으므로 아동을 포함한 모든 이용자로부터 정보를 수집하지 않습니다.

6. 이용자의 권리

저장된 데이터는 전적으로 사용자 기기 안에 있으므로, 앱 안에서 단어를 삭제하거나 앱을 삭제하는 것만으로 언제든지 모든 데이터를 완전히 지울 수 있습니다. 개발자가 보관하는 사용자 데이터가 없어 별도의 열람·정정·삭제 요청 절차는 필요하지 않습니다.

7. 방침 변경

이 방침이 변경되면 이 페이지에 수정된 내용과 최종 수정일을 게시합니다.

プライバシーポリシー

最終更新日: 2026年8月21日

要約 — このアプリはアカウント登録がなく、利用者を識別する情報を収集したりサーバーに保存したりしません。保存した単語はすべて利用者の端末内にのみ残ります。

1. 収集する個人情報

ありません。 氏名・メールアドレス・電話番号・位置情報・連絡先・端末識別子などの個人を識別できる情報は一切収集しません。ログイン機能はなく、広告や解析ツール（SDK）も使用していません。

2. 端末に保存される情報

追加した単語と単語帳（意味・発音・例文・学習状態）、表示設定（言語・テーマ）、チュートリアルの表示状況が、ブラウザのローカルストレージに端末内にのみ保存されます。開発者を含む外部から閲覧することはできません。アプリを削除するとこれらのデータも消え、バックアップサーバーがないため復元できません。

3. 外部に送信される情報

辞書検索を使うときに限り、入力した検索語が辞書照会のためサーバーに送信されます。検索語は照会の目的にのみ使われ、利用者のアカウントや身元と結び付けられることはなく、別途保存もしません。

利用する外部サービス: 国立国語院 韓国語基礎辞典オープンAPI（単語の意味・発音・例文の照会）、Vercel（アプリのホスティングとAPI中継。通常のサーバー運用の過程でアクセス記録が一定期間残る場合があります）、Google Fonts・jsDelivr（フォントの配信）。

4. アプリが求める権限

カメラ・マイク・位置情報・連絡先・ストレージなど、いかなる端末の権限も要求しません。 辞書検索と発音再生のためにインターネット接続のみを使用します。

5. 利用者の権利

データはすべて端末内にあるため、アプリ内で単語を削除するか、アプリを削除することで、いつでもすべてのデータを完全に消去できます。
